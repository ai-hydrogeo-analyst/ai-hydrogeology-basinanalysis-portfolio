# AI-Hydrogeologist-Portfolio
AI Hydrogeologist specializing in groundwater recharge, land subsidence, and water stress analysis combining satellite remote sensing and machine learning for the Indus Basin.

## Focus Areas

Groundwater recharge estimation
Land subsidence monitoring (InSAR)
Water stress analysis
Flood risk modeling
Managed Aquifer Recharge (MAR)

## Tools & Stack

- **GIS:** QGIS, ArcGIS
- **Remote Sensing:** Google Earth Engine, Sentinel-1/2, Landsat, GRACE
- **Python:** GeoPandas, Rasterio, Xarray, scikit-learn
- **Modeling:** MODFLOW, FloPy, HEC-HMS
- **AI/ML:** TensorFlow, scikit-learn, Hugging Face
- **Visualization:** Matplotlib, Tableau, Datawrapper
